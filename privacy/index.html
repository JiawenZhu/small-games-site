Small Games

Privacy

Last updated 7 November 2026. Applies to Nyandoku, Save Doge, Apple Worm, Paradox Box and Isle of Glass.

These are small puzzle games. They do not ask you for anything about yourself, and there is no account to create and no server of ours for them to talk to.

What is stored, and where

Each game saves your progress — which levels you have finished, how many stars you earned, and whether you muted the sound. That data stays on your own device, in the browser's local storage or in the host app's storage. It is never sent anywhere, and we cannot read it. Clearing the site data or the app's storage erases it.

Signing in

Inside TikTok, the games call TikTok's silent login, which hands the game a short-lived authorization code. We do not exchange that code for an access token and we do not store it, so no TikTok profile information reaches us. What TikTok itself collects is covered by TikTok's privacy policy.

Advertising

The games can show a rewarded video, which you choose to watch, and occasionally an interstitial between levels. Those ads are served by TikTok, not by us. We see only whether an ad finished, so the game knows whether to grant the reward. Ad personalisation is controlled in your TikTok settings, not here.

Analytics

None. There is no analytics script in the games and none on this site.

Children

The games have no chat, no user accounts, no social features and no way for players to contact each other or to publish anything.
